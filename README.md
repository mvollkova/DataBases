This repository contains a database project focused on movies.

Description  
It includes SQL scripts for:
- creating and deleting database structures,  
- inserting sample data,  
- executing queries and creating views.

Files
- `create.sql` – creates the database schema  
- `insert.sql` – inserts sample movie data  
- `drop.sql`, `cascade.sql` – database cleanup scripts  
- `1.sql`–`7.sql` – example SQL queries(folder sql_queries)
- `3_widok_create.sql`, `3_widok_usse.sql` – examples of SQL views
